About PromptVault

A shared shelf of prompts that already work, so nobody starts from a blank box.

Why it exists

Good prompts take trial and error. People rewrite the same instructions again and again, and the best ones end up lost in chat histories. PromptVault collects them in one place so they can be found, adapted and improved by everyone.

What makes a prompt here

Each prompt has a clear purpose, a stated difficulty, instructions for using it and an example. The parts you are meant to change sit in [square brackets]. On the site those turn into fields, so you can fill them in and copy a finished prompt.

Prompts are written to work with any capable assistant, including ChatGPT, Claude and Gemini. Results still vary by model, so treat them as strong starting points and adjust.

How it works

  • The library is a single JSON file in the repository, so changes are easy to review.
  • The site is built with Flask, then exported to plain HTML so it can be hosted for free on GitHub Pages. No server, no accounts, no tracking.
  • Favorites and your theme are saved in your own browser.
  • The code and the prompts are open source under the MIT license.

Get involved

Use a prompt, improve one, or add your own. Submit a prompt or read the GitHub contribution guide. Bugs and ideas go in the issue tracker.
