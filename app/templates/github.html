Contribute on GitHub

The whole library is one file, data/prompts.json. Adding a prompt means adding one entry to it and opening a pull request.

Open the repositoryRead CONTRIBUTING.md

  1. Fork the repository

    On GitHub, click Fork on the repository page. This makes your own copy under your account.

  2. Clone your fork

    git clone https://github.com/YOUR-USERNAME/promptvault.git
cd promptvault
git checkout -b add-my-prompt

  3. Add your prompt

    Open data/prompts.json and add an entry to the end of the "prompts" list. Remember the comma between entries.

    {
  "slug": "my-prompt-title",
  "title": "My Prompt Title",
  "description": "One or two sentences on what it does.",
  "category": "writing-communication",
  "tags": ["email", "tone"],
  "difficulty": "Beginner",
  "prompt": "Full prompt text with [PLACEHOLDERS] for the parts to change.",
  "instructions": ["Replace the bracketed fields."],
  "example_input": "A short example of what you would type.",
  "example_output": "An abridged example of the result.",
  "popularity": 0,
  "date_added": "2026-01-31",
  "featured": false,
  "author": "your-github-username"
}

    Valid categories: {% for c in all_categories %}{{ c.slug }}{% if not loop.last %}, {% endif %}{% endfor %}.

  4. Check it

    The validator catches typos, missing fields and duplicate slugs. Then run the site and look at your prompt.

    python tools/validate_prompts.py
python run.py

  5. Commit and push

    git add data/prompts.json
git commit -m "Add prompt: My Prompt Title"
git push origin add-my-prompt

  6. Open a pull request

    On your fork, click Compare & pull request, describe what the prompt does and how you tested it, then submit. A maintainer will review it and may ask for changes.

Not comfortable with Git? Use the submission form instead.
